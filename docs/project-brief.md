# Итоги онбординга

## Общее

| Параметр | Значение |
|----------|----------|
| Название | Тест по курсу "Транспортная логистика" |
| Описание | Тест для менеджера операционного отдела ЕС Транс по ГФД. Сотрудник проходит тест по ссылке, результаты сохраняются и отправляются руководителю на почту. |
| Дата старта | 2026-09-12 |

## Технические решения

| Параметр | Значение |
|----------|----------|
| Размещение | Свой сервер |
| Подключение к Б24 | Без Битрикс24 (данные Б24 не используются) |
| Где открывается | Отдельная страница в браузере, без авторизации |
| Бэкенд | Node.js (Express) — сохранение результатов и отправка email через Resend (с fallback на SMTP) |
| Дизайн | Корпоративный стиль ЕС Транс (белый фон, красный акцент, тёмный текст) |
| Домен | test-logistics.es-trans.ru (DNS уже настроен, деплой через `vibe-deploy-service`) |

## Доступы и ключи

| Параметр | Где хранится |
|----------|-------------|
| RESEND_API_KEY | .env |
| RESEND_FROM | .env |
| MANAGER_EMAIL | .env (kpv@es-trans.pro) |
| SMTP_HOST / SMTP_PORT / SMTP_USER / SMTP_PASS | .env (fallback, если Resend недоступен) |

## Особенности проекта

- Банк вопросов: 15 вопросов по курсу "Транспортная логистика" в `src/data/questions.js` (и продублирован во фронтенде `src/public/js/test.js`)
- Распределение правильных ответов: А=3, Б=4, В=4, Г=4 — примерно равномерно
- 5 вариантов порядка вопросов (одинаковый набор, разный порядок) — переключаются через `localStorage`
- Email руководителю: приоритет — Resend API (HTTP, работает даже если SMTP-порты на VPS заблокированы), fallback — SMTP через nodemailer, если RESEND_API_KEY не задан. Логика перенесена из проекта es-trans-test-OM (`src/services/mailer.js`)
