# Проект: тест по курсу «Транспортная логистика»

## Суть

Веб-тест для сотрудников, проходящих курс «Транспортная логистика». Исходный материал —
45 открытых экзаменационных вопросов (5 тематических блоков) с конспектами по каждому вопросу,
загруженные пользователем в репозиторий `https://github.com/krutko77/transport-logistics-course.git`.

Так как формат сайта требует тест с выбором ответа (не эссе), все 45 вопросов были
переработаны в формат «вопрос + 4 варианта + 1 правильный ответ» на основе фактического
содержания конспектов.

## Структура вопросов

| Блок | id | Тема |
|------|-----|------|
| 1 | 1–10 | Виды транспорта, классификация грузов, тара, контейнеры |
| 2 | 11–20 | Габариты ТС, маркировка, документы, CMR, авиаперевозки |
| 3 | 21–27 | Стоимость груза, склады, мониторинг, международные конвенции |
| 4 | 28–36 | Режим труда, разрешения, таможня, МДП, Инкотермс, договоры |
| 5 | 37–45 | Страхование, тарифы, ответственность перед таможней ЕАЭС |

Распределение правильных ответов по позициям А/Б/В/Г: 12/11/11/11 (сбалансировано).

## Система вариантов

5 вариантов по 25 вопросов из банка 45. Каждый вариант пропорционально охватывает
все 5 блоков (6+5+4+5+5 = 25). Вместе все 5 вариантов покрывают все 45 вопросов банка.
Вариант меняется автоматически при каждой новой попытке (ротация через `localStorage`).
