  `POST /api/results` — сравнение ответов по тексту (`answerTexts`), а не по
  индексу, так как позиция ответа больше не фиксирована

  домен от старого конфликтующего проекта; SSL выпущен автоматически при

- Добавлен брендинг ЕС Транс: логотип (`logo.svg`) и favicon перенесены из
  проекта `es-trans-test-OM` в шапку сайта вместо текстового заголовка
- Уменьшена толщина красной линии под шапкой с 3px до 2px (по требованию)
- Акцентный цвет проекта сменён с красного (`#CC0000`) на синий (`#0098DD`) —
