# Состояние проекта

**Последнее обновление:** 2026-09-12

## Где мы сейчас
Проект «Тест по курсу «Транспортная логистика»» задеплоен и работает на
`https://test-logistics.es-trans.ru/`. Синхронизирован с GitHub-репозиторием
`https://github.com/krutko77/transport-logistics-course.git` (ветка `main`).
Банк из 45 вопросов разбит на 5 реальных тематических блоков курса. Тест
состоит из 2 вариантов по 25 вопросов (по 5 из каждого блока), которые вместе
покрывают весь банк из 45 вопросов без пропусков — при повторном прохождении
подставляется следующий вариант. Порядок вариантов ответа (А/Б/В/Г)
перемешивается динамически при каждом показе вопроса. Приём результатов
переведён на сравнение по тексту ответа (`answerTexts`), а не по индексу —
из-за клиентской рандомизации порядка. Деплой — через `vibe-deploy-service`,
SSL выпущен автоматически при первом деплое. Визуально проект приведён к
корпоративному стилю ЕС Транс: логотип и favicon перенесены из
`es-trans-test-OM`, акцентный цвет сменён с красного на синий (`#0098DD`).

## Сейчас в работе
Активная разработка приостановлена. Приложение задеплоено и открывается по
HTTPS без предупреждений (подтверждено пользователем скриншотами). Полный
цикл теста (прохождение → сохранение результата → письмо руководителю на
реальном сервере) пользователем ещё не подтверждён явно.

## Следующие шаги

  `data/results/` на сервере и письмо доходит до `MANAGER_EMAIL`
  (`RESEND_API_KEY` намеренно оставлен пустым — используется SMTP fallback).
- При необходимости — донастроить `RESEND_API_KEY`/`RESEND_FROM`, если
  пользователь решит перейти на Resend вместо SMTP.
- Дальнейшие правки дизайна (если будут) — вносить через тот же цикл:
