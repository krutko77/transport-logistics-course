# Журнал решений

Формат записи:

```
## D-NNN — Короткое название

**Контекст:** какую задачу решали
**Варианты:** что рассматривали
**Решение:** что выбрали
**Почему:** главная причина + чем пожертвовали
**Последствия:** на что влияет дальше
```

Записи добавляются НИЖЕ этой строки-маркера, по возрастанию номера.
