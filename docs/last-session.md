- При конфликте домена на этапе первого деплоя — не обходить защиту
  `vibe-deploy-service`, а дождаться администратора портала (пользователь
  подтвердил это как предпочтительный путь)
- При нехватке вопросов в малых блоках (3/4/5) для строгого разделения 5+5
  без повторов — допущено минимальное пересечение вопросов между двумя
  вариантами (подтверждено пользователем)
- Рандомизация порядка ответов — динамическая при каждом показе вопроса, а
  не фиксированная на вариант (подтверждено пользователем)

  ожидаемое поведение)

  файлы — проверять с жёстким обновлением (Ctrl+F5)
