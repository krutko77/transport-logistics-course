# transport-logistics-course

Тест для сотрудников по курсу «Транспортная логистика».
Сотрудник проходит тест по ссылке, результаты сохраняются на сервере и отправляются руководителю на почту.

## Язык общения

Все рассуждения, объяснения и текстовые ответы — только на русском языке.

## О проекте

**Название:** transport-logistics-course
**Описание:** Тест по курсу «Транспортная логистика» — 45 вопросов в банке, 5 тематических блоков, 5 вариантов по 25 вопросов.
**Портал Б24:** не используется — проект не связан с Битрикс24/VibeCode
**Размещение:** свой сервер
**Подключение к Б24:** без Битрикс24
**Где открывается:** отдельная страница в браузере
**Бэкенд:** Node.js (Express) — сохранение результатов и отправка email
**Дизайн:** нейтральный корпоративный стиль (белый фон, красный акцент)
**Авторизация:** не нужна — приложение открыто по ссылке

## Стек

- Node.js 20 + ES modules (`"type": "module"`)
- Express 4
- Vanilla JS + CSS — фронтенд без фреймворков
- Resend API (основной способ отправки email) с fallback на SMTP через nodemailer

## Банк вопросов

45 вопросов, разбиты на 5 блоков:
- Блок 1 (id 1–10): виды транспорта, классификация грузов, тара, контейнеры
- Блок 2 (id 11–20): габариты ТС, маркировка, документы, CMR, авиаперевозки
- Блок 3 (id 21–27): стоимость груза, склады, мониторинг, международные конвенции
- Блок 4 (id 28–36): режим труда, разрешения, таможня, МДП, Инкотермс, договоры
- Блок 5 (id 37–45): страхование, тарифы, ответственность перед таможней ЕАЭС

Correct-answer позиции сбалансированы: 12/11/11/11 по А/Б/В/Г.

5 вариантов по 25 вопросов (см. `VARIANTS` в `src/public/js/test.js`), каждый охватывает все 5 блоков.
Вариант меняется при каждом новом прохождении через `localStorage` (ключ `tlc_variant`).

## Команды

```bash
npm install
cp .env.example .env   # заполнить MANAGER_EMAIL и RESEND_API_KEY (или SMTP_*)
npm run dev             # локальный запуск с авто-перезагрузкой
npm start                # продакшн-режим
```

## Правило деплоя

После каждого изменения кода — задеплоить на сервер и перезапустить процесс (см. `docs/test-app-template.md` в проекте es-trans-test-OM за паттерном деплоя через scp + PM2 + nginx + certbot).
Детали конкретного сервера (IP, домен) — уточнить у пользователя при первом деплое.

## Ключи и безопасность

Ключи — только в `.env`, который не попадает в git. В git — только `.env.example`.
